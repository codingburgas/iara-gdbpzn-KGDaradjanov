## 🔐 Роли и права за достъп (RBAC)

Системата разделя потребителите на три нива:

- **Рибар (Fisherman)** — по подразбиране за всеки нов акаунт. Може да купува
  билети, да регистрира кораби, да кандидатства за стопански разрешителни, да
  подава електронни дневници (любителски и стопански) и да генерира PDF отчети.
- **Инспектор (Inspector)** — достъп до „Полеви терминал“. Може да проверява
  валидността на документи по ID и да съставя актове (глоби) при нарушения.
- **Администратор (Admin)** — пълен достъп чрез централизирано табло с KPI
  метрики (общо потребители, общо билети, регистрирани кораби). Управлява
  ролите на всички потребители.

> Ролите се задават чрез скриптовете `make_admin.py` и `make_inspector.py`
> (виж по-долу).

## 🛠️ Използвани технологии

- **Python (Flask)** — сървър (backend) и рутинг
- **Flask-SQLAlchemy** — ORM за работа с базата данни
- **SQLite** — база данни (`instance/iara_system.db`)
- **Werkzeug security** — хеширане на пароли
- **ReportLab** — генериране на PDF отчети
- **OpenWeatherMap API** — данни за времето в Бургас (чрез `requests`)
- **python-dotenv** — зареждане на API ключ от `.env` файл
- **HTML5, CSS3, JavaScript** — потребителски интерфейс

## ▶️ Как да стартирате проекта

Нужен е инсталиран **Python 3.10+**. Проверете с:

```bash
python --version
```

Ако нямате Python, изтеглете го от <https://www.python.org/downloads/>
(при инсталация **сложете отметка „Add Python to PATH“**).

### 1. Инсталирайте зависимостите

```bash
pip install flask flask-sqlalchemy werkzeug reportlab requests python-dotenv
```

### 2. Настройте API ключ за времето (по избор)

Създайте файл `.env` в основната папка на проекта:

```
WEATHER_API_KEY=твоят_ключ_от_openweathermap.org
```

> Без ключ системата продължава да работи — просто без данни за времето.

### 3. Стартирайте сървъра

```bash
python app.py
```

Отворете в браузъра: **<http://localhost:5000>**

### 4. Регистрирайте акаунт и си дайте права (по избор)

1. Отворете `/register` и си направете акаунт (по подразбиране е роля "Рибар").
2. За да станете **Администратор**:
   ```bash
   python make_admin.py
   ```
3. За да станете **Инспектор**:
   ```bash
   python make_inspector.py
   ```
   *(и двата скрипта задават ролята на първия регистриран потребител в базата)*

## 🗄️ Структура на базата данни

| Модел | Описание | Връзки |
|-------|----------|--------|
| `User` | Потребител (username, парола, роля) | 1:N към Ticket, Vessel, Fine, CatchLog |
| `Ticket` | Билет за любителски риболов | принадлежи на User |
| `Vessel` | Риболовен кораб (регистрация, тонаж, капитан...) | принадлежи на User, 1:1 към CommercialPermit |
| `CommercialPermit` | Стопанско разрешително за кораб | принадлежи на Vessel |
| `Fine` | Съставен акт (глоба) от инспектор | съставя се от User с роля Inspector |
| `CatchLog` | Запис в е-дневника (вид риба, количество, GPS) | свързва се с User (любителски) или Vessel (стопански) |
